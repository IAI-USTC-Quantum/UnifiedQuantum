## 已知缺口（外部原因，不阻塞发布）

1. **OriginQ 实时发现上游故障**：`pyqpanda3` 0.4.1（PyPI 最新，已核实）的
   `QCloudService.backends()` 直接抛 `RuntimeError: value is not array
   (which is 3)`（用原始 SDK 裸调用复现，在本项目代码之下）。本地自动回退
   stale 缓存（7 个后端可用）；`chip-display --update` 对 Quark/TianYan
   实测正常，确认为 OriginQ 特异问题。
2. **IBM token 失效**：IBM Quantum 返回 "Unable to retrieve instances"，
   属凭据问题；stale 缓存（3 个后端）回退可用。
3. **真实量子任务未提交**：本轮未获配额授权，`--real-cloud-test` 变体未运行；
   维护者已明确接受该缺口。
4. **Gateway 视觉覆盖**：验证环境无 Playwright/浏览器，以 HTTP + 构建产物
   检查代替。

## 行为确认（非缺陷）

- `dummy:originq:WK_C180` dry-run 对 CNOT(0,1) 报 "Unsupported topology" 是
  预期行为（该芯片无 0–1 耦合边）；换耦合对 (0,9) 即通过。对应
