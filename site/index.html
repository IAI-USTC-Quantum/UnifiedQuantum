核心能力

一套框架，覆盖全链路

从线路构建到误差缓解，UnifiedQuantum 提供量子计算所需的完整工具链。

统一电路构建

一致的 API 构建量子线路，支持原生构建器及 Qiskit / Cirq 导入，输出 OriginIR 或 OpenQASM 2.0。

多平台后端

聚合 OriginQ、IBM Quantum、QuarkStudio、天衍、逻辑比特等量子云平台，一套代码切换后端。

本地仿真

状态向量与密度矩阵模拟，支持 MPS 与含噪模拟；复用真实芯片拓扑数据，无需云端凭证即可开发调试。

芯片标定

uniqc calibrate xeb 交叉熵基准测试，逐层门保真度测量，读出误差矩阵标定，结果自动缓存与 TTL 管理。

误差缓解（QEM）

M3 矩阵无关测量误差缓解与线性求逆修正，结合标定数据自动应用于测量结果。

CLI & WebUI

功能完整的命令行工具 uniqc，以及 WebUI 可视化管理任务、查看结果，AI 友好的 --ai-hints。

快速上手

三分钟，从安装到运行

Python API 
from uniqc import Circuit, submit_task, wait_for_result

c = Circuit()
c.h(0)
c.cnot(0, 1)
c.measure(0, 1)

task_id = submit_task(c, backend="dummy:local:simulator", shots=1024)
print(wait_for_result(task_id))
CLI 
# 本地模拟
uniqc simulate circuit.ir --shots 1000

# 提交到本源 WK_C180 真机
uniqc submit circuit.ir --backend originq:WK_C180 --shots 1000

# 查询任务结果
uniqc result <task_id>
